# 📚 Library Management System

A simple and interactive Library Management System developed using HTML, CSS, and JavaScript. This project helps librarians manage books, members, borrowing, returning, and library statistics through a user-friendly web interface.

---

## 🚀 Features

### 📖 Book Management
- Add new books with:
  - ISBN
  - Book Title
  - Author Name
  - Publication Year
- Prevent duplicate ISBN entries
- Delete books from the library
- View all books in a tabular format

### 🔍 Search Books
- Search books by title
- Instantly display matching results

### 👥 Member Management
- Register new library members
- Store member information using browser Local Storage

### 📚 Borrow & Return Books
- Borrow books using:
  - ISBN
  - Member ID
- Automatic due date generation (14 days)
- Return borrowed books
- Update availability status automatically

### 📊 Library Statistics Dashboard
- Total Books
- Available Books
- Borrowed Books
- Registered Members
- Overdue Books

### 💾 Data Persistence
- Uses Browser Local Storage
- Data remains available even after refreshing the page

## ⚙️ Installation

1. Clone the repository:


```bash

```

3. Open `index.html` in your browser.

## 🎯 How to Use

### Add a Book
1. Click **Add Book**
2. Enter:
   - ISBN
   - Title
   - Author
   - Publication Year
3. Click **Add Book**

### Search a Book
1. Click **Search Book**
2. Enter the book title
3. Click **Search**

### Register a Member
1. Click **Register Member**
2. Enter Member ID and Name
3. Click **Register**

### Borrow a Book
1. Click **Borrow Book**
2. Enter ISBN
3. Enter Member ID
4. Click **Borrow**

### Return a Book
1. Click **Return Book**
2. Enter ISBN
3. Click **Return**

### View Statistics
1. Click **Statistics**
2. View real-time library information
